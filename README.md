# Transparency for Patients at Home

A mobile application built with React Native and Expo to provide transparency and care management for patients receiving care at home. Helping family members and hospital staffs to monitor and update patients health remotely.

## Design

Figma design: 
https://www.figma.com/design/kSAOnAGbppBlpxJDe8xiPQ/Elements-for-OTFPAH?node-id=1-2&t=yBwrl0LqGztYRYda-1

## Features

- **Appointments Management**: View and manage patient appointments with calendar interface
- **Visit Summaries**: Access homecare visit summaries and care reports
- **Chat**: Communication interface for patient-provider messaging
- **Checklist**: Track care tasks and activities
- **Profile Management**: View and update patient profile information
- **Appointment History**: Review past appointments and care visits
- **Role changing**: Change role in user profile to view the different functions.

## Tech Stack

- React Native
- Expo
- TypeScript
- Express.js (backend server)

## Getting Started

### Prerequisites

- Node.js
- npm or yarn
- Expo CLI

### Installation

```bash
npm install
```

### Running the App

```bash
npm start
```

### Running the Backend

```bash
node server.js
```
